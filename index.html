ℹ Health status rules

Reading results: results are read from the left. Example XBBACC → latest result X, trend (last 3) X B B. “_” means no sample.


SOS / Magnetic Plug / Cutting Filter (latest result)

  • X Extreme (dark red)
  • C Critical (red)
  • B Caution (yellow)
  • A Normal (green)

Combined rule: if latest SOS = B and Magnetic Plug = B and Cutting Filter = B → component becomes Critical.


CTS

  • A → Normal
  • B → Caution · Please order the parts
  • C → Critical · Please schedule the replacement
  • X → Extreme · Replace the parts immediately

Component status = the worst result of SOS, Magnetic Plug, Cutting Filter, CTS and the combined rule. Components with none of these results are No Data and are not counted in the pie chart. Component life % is shown separately (purple KPI) and does not change the health status.
